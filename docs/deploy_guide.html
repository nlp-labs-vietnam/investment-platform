2. VPS / Server — User THƯỜNG (sudo) user

⚠️ Dùng sudo cho các lệnh cần quyền hệ thống. Không có quyền ghi vào /etc/nginx/ trực tiếp — nhờ admin hoặc dùng sudo.

Bước 1 — Tải & giải nén

cd ~
wget https://nlpgroup.vn/backup_20261021_054255.tar.gz
tar -xzf backup_20261021_054255.tar.gz
cd backup_20261021_054255

Bước 2 — Deploy source

sudo tar -xzf source_code.tar.gz -C /var/www/
cd ./nlp-labs-vietnam

sudo composer install --no-dev --optimize-autoloader
sudo npm ci && sudo npm run build

sudo chown -R www-data:www-data ./nlp-labs-vietnam
sudo chmod -R 775 storage bootstrap/cache
sudo php artisan storage:link

Bước 3 — Restore DB

mysql -u invest_user -pinvest_pass_2025 investment_platform \
  < storage/app/backups/investment_platform_db.sqllt; storage/app/backups/storage/app/backups/investment_platform_db.sql

sudo cp deploy/nginx/nginx.conf /etc/nginx/nginx.conf

4. Kiểm tra sau deploy (mọi loại máy chủ)

# Chạy migrations (nếu DB trống / máy mới)
php artisan migrate --force

# Clear cache
php artisan cache:clear
php artisan config:clear
php artisan view:clear

# Seed dữ liệu mẫu (tùy chọn)
php artisan db:seed --force

# Kiểm tra queue worker (nếu dùng)
php artisan queue:work --daemon
✔ Truy cập domain → thấy trang chủ = deploy thành công!
