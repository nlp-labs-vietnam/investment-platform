YÊU CẦU TRƯỚC KHI CÀI ĐẶT
────────────────────────────────────────────────────────────────────────────────
  • Hosting cPanel có hỗ trợ SSH Terminal
  • PHP 8.1 hoặc 8.2 (bật trong cPanel → MultiPHP Manager)
  • MySQL đã được tạo sẵn (xem Bước 1 bên dưới)
  • Dung lượng trống tối thiểu: 300 MB

================================================================================
BƯỚC 1 — TẠO DATABASE MYSQL TRÊN CPANEL
================================================================================

  1. Đăng nhập cPanel → kéo xuống mục "Databases"
  2. Click "MySQL Databases"
  3. Tạo database mới:
       Tên database : nlp03448_db   (ghi nhớ lại)
  4. Tạo user mới:
       Tên user     : nlp03448_user      (ghi nhớ lại)
       Mật khẩu    : nlp03448   (ghi nhớ lại — tối thiểu 8 ký tự)
  5. Gán user vào database:
       Chọn user "nlp_user" + database "nlpgroup_db" → Add User To Database
       → Tích "ALL PRIVILEGES" → Make Changes

================================================================================
BƯỚC 2 — TẢI MÃ NGUỒN QUA SSH (wget)
================================================================================

  Mở cPanel → "Terminal" (hoặc SSH client như PuTTY)

  Chạy lần lượt từng lệnh sau:

  ── Chuyển vào thư mục public_html ──────────────────────────────────────────

    cd  ./domains/nlpgroup.com/public_html

  ── Tải file zip từ máy chủ NLP Group ──────────────────────────────────────

    wget https://nlpgroup.vn/nlpgroup-platform-20261019_134107.zip

  ── Giải nén ────────────────────────────────────────────────────────────────

    unzip nlpgroup-platform-20261019_134107.zip

  ── Nếu zip giải nén ra thư mục con, chuyển nội dung ra ngoài ──────────────

    mv investment-platform/* .
    mv investment-platform/.* . 2>/dev/null || true
    rmdir investment-platform

  ── Xóa file zip sau khi giải nén (giải phóng dung lượng) ──────────────────

    rm nlpgroup-platform-20261019_134107.zip

================================================================================
BƯỚC 3 — CHẠY SCRIPT CÀI ĐẶT TỰ ĐỘNG
================================================================================

  Vẫn trong Terminal, chạy:

    chmod +x install_cpanel.sh && bash install_cpanel.sh

  Script sẽ hỏi lần lượt:
    • Thư mục cài đặt   → nhấn Enter (dùng thư mục hiện tại)
    • Tên miền          → nhập: vnegreen.com
    • Tên Database      → nhập: nlp03448_db  (đã tạo ở Bước 1)
    • Tên User MySQL    → nhập: nlp03448_db
    • Mật khẩu MySQL    → nlp03448_db
    • DB Host           → nhấn Enter (mặc định: localhost)
    • Email quản trị    → nhập email của bạn
    • Xác nhận          → nhập: y

  Script sẽ tự động:
    ✔ Tạo file .env với APP_KEY mới
    ✔ Cài đặt PHP dependencies (composer install)
    ✔ Tạo .htaccess chuẩn cho cPanel
    ✔ Chạy database migration
    ✔ Tối ưu cache ứng dụng

================================================================================
BƯỚC 4 — CẤU HÌNH DOCUMENT ROOT TRÊN CPANEL
================================================================================

  Sau khi cài xong, cần trỏ domain vào thư mục /public:

  Cách 1 — Qua cPanel Domains:
    cPanel → Domains → tìm nlpgroup.com → Edit → Document Root
    → Đổi thành:  ./domains/nlpgroup.com/public_html/public
    → Save

  Cách 2 — Qua Subdomains (nếu dùng subdomain):
    cPanel → Subdomains → tìm domain → Edit Document Root
    → Đổi thành:  ./domains/nlpgroup.com/public_html/public

  Cách 3 — File .htaccess (nếu không đổi được Document Root):
    File .htaccess đã được tạo tự động tại public_html/
    Không cần làm gì thêm.

================================================================================
BƯỚC 5 — BẬT SSL MIỄN PHÍ
================================================================================

  cPanel → SSL/TLS → Manage AutoSSL
  → Click "Run AutoSSL For All Users"

  Hoặc: cPanel → SSL/TLS Status → Issue/Renew certificate cho nlpgroup.com

================================================================================
BƯỚC 6 — THIẾT LẬP CRON JOB
================================================================================

  cPanel → Cron Jobs → Add New Cron Job

  Cài đặt thời gian: * * * * * (mỗi phút)
  Command:
    php  ./domains/nlpgroup.com/public_html/artisan schedule:run >> /dev/null 2>&1

LỆNH QUẢN LÝ QUA SSH
================================================================================

  cd  ./domains/nlpgroup.com/public_html

  # Xóa cache khi cần
  php artisan optimize:clear

  # Xem log lỗi
  tail -f storage/logs/laravel.log

================================================================================
XỬ LÝ SỰ CỐ THƯỜNG GẶP
================================================================================

  ❌ Lỗi 500 Internal Server Error
     → Kiểm tra: cat storage/logs/laravel.log | tail -50
     → Thử: php artisan config:clear && php artisan cache:clear

  ❌ Lỗi "No application encryption key"
     → Chạy: php artisan key:generate --force

  ❌ Trang trắng / không load được
     → Kiểm tra Document Root đã trỏ vào /public chưa
     → Kiểm tra .htaccess đã tồn tại chưa: ls -la public/.htaccess

  ❌ Lỗi kết nối Database
     → Kiểm tra thông tin trong file .env:
        cat .env | grep DB_
     → Đảm bảo user MySQL đã được gán ALL PRIVILEGES

  ❌ Lỗi "Permission denied" trên storage/
     → Chạy: chmod -R 755 storage bootstrap/cache

  ❌ wget báo lỗi certificate
     → Thêm flag: wget --no-check-certificate <url>
